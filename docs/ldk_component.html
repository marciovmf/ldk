LDKComponentFlags

A descriptor that identifies a Component. Components are plain data structures that can be attached to entities. Component types needs to be registered before they are used.

typedef enum LDKComponentFlags{
  LDK_COMPONENT_FLAG_NONE=0,
  LDK_COMPONENT_FLAG_HIDE_IN_INSPECTOR=1<<0
}LDKComponentFlags;
