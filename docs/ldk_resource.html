ldk_resource.h

home

Renderer resource handles

Generic renderer-facing resource handle.

Renderer resources use the same opaque storage type as RHI resources, but they are not necessarily direct RHI objects. A mesh, for example, may be a renderer-owned object that contains multiple RHI buffers.
