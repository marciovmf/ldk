ldk_scene_from_tml

Loads entities and components from a TML string into the current ECS. This function does not clear existing entities and does not roll back entities created before an error. A caller performing a full scene replace is responsible for clearing the ECS before the call and after a failed call.

 const char *source,

ldk_scene_from_tml_with_systems

Load entities and scene-owned system data together, resolving references with the same entity map. Systems is initialized with {0}; on failure its previous contents are unchanged. The caller owns ECS cleanup on failure, and must stop old systems before replacing a scene. No initialize runs.
