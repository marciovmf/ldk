ldk_ttf_utf8_consume_codepoint

Consumes one UTF-8 codepoint and advances the input cursor.

LDK_API bool ldk_ttf_utf8_consume_codepoint(
 char const **cursor,
 u32 *out_codepoint
);

Parameters

char const **cursor
Pointer to the current UTF-8 string position. Updated to the next byte after the decoded sequence.
u32 *out_codepoint
Destination for the decoded Unicode codepoint.

Returns

true if a codepoint was consumed, false if input is invalid or the cursor is at the string terminator.

ldk_ttf_utf8_consume_codepoint_range

Consumes one UTF-8 codepoint within a bounded byte range and advances the input cursor.

LDK_API bool ldk_ttf_utf8_consume_codepoint_range(
 char const **cursor,
 char const *end,
 u32 *out_codepoint
);

Parameters

char const **cursor
Pointer to the current UTF-8 string position. Updated to the next byte after the decoded sequence.
char const *end
Exclusive end pointer for the UTF-8 byte range.
u32 *out_codepoint
Destination for the decoded Unicode codepoint.

Returns

true if a codepoint was consumed, false if input is invalid, the cursor is at the string terminator, or the cursor reached end.
