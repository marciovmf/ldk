ldk_material_desc_defaults

Initialize a material descriptor with deterministic defaults. Every supported material type defaults to opaque white, opaque alpha mode, and a 0.5 cutout threshold. Textured materials also default to a null image asset, nearest filtering, no mip filtering, clamp-to-edge wrapping, and identity UV transform. Additional texture slots default to null. Lit materials default to no specular contribution, shininess 32, no emission, and no normal/specular maps. On failure, out_desc is reset to an invalid zero descriptor.

LDK_API bool ldk_material_desc_defaults(
 LDKMaterialType type,
 LDKMaterialDesc *out_desc
);

Parameters

LDKMaterialType type
Material type whose defaults should be produced.
LDKMaterialDesc *out_desc
Destination descriptor.

Returns

true on success, false for an invalid type or null destination.

Function in ldk_material.h

ldk_material_desc_is_valid

Check whether a descriptor has a supported material type. This validates the descriptor structure only. Asset availability is validated later by the asset/material resolver. Textured cutout thresholds must be finite and within [0, 1]. Active lit surface values must be finite and non-negative. A zero shininess is canonicalized to the default value (32) so zero-initialized descriptors remain valid.

LDK_API bool ldk_material_desc_is_valid(LDKMaterialDesc const *desc);

Parameters

LDKMaterialDesc const *desc
Descriptor to inspect.

Returns

true when the descriptor is structurally valid.
