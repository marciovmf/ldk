Color values

RGB and RGBA color types and helpers

Defines color structures, constructors, and named color constants.

ldkRGB

Construct a color value from individual channel components.

LDK_API LDKRGB ldkRGB(
 u8 r,
 u8 g,
 u8 b
);

Parameters

u8 r
R color channel.
u8 g
G color channel.
u8 b
Second value to compare or combine.
