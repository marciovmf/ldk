ldk_scene_systems_from_tml

Reads the optional scene.systems node without creating ECS entities. This is association preflight only; use ldk_scene_from_tml_with_systems or ldk_scene_load_tml_file_with_systems to load fields and entity references. An absent node produces an empty list. On failure, out is unchanged. Accepted ids are positive signed integers or strings representing u64s. The writer uses quoted hexadecimal strings to support the full u64 range. Legacy grouping entries are ignored. scene: systems: - id: "0x0000000000000100"

LDK_API bool ldk_scene_systems_from_tml(
 const char *source,
 LDKSceneSystems *out,
 LDKSceneResult *result
);

Parameters

const char *source
Source object or source data for this operation.
LDKSceneSystems *out
Output object or buffer receiving the result.
LDKSceneResult *result
Optional result structure populated with error details.

Returns

True if the operation succeeds; false otherwise.
